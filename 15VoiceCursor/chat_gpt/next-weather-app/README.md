# Next Weather App

This is a simple Next.js app to show the weather for any city you type in.

## How to Use

1. Install dependencies:
   ```bash
   npm install
   ```
2. Get a free API key from https://openweathermap.org/api
3. Replace `YOUR_OPENWEATHERMAP_API_KEY` in `pages/index.tsx` with your API key.
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Visit [http://localhost:3000](http://localhost:3000) and use the app!
