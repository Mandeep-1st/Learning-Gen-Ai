* **string**: Used as-is. If additional arguments are supplied after the
  `message` string, they are treated as printf-like substitutions (see
  [`util.format()`][]).
* **Error**: If an `Error` instance is provided as `message`, that error is
  thrown directly instead of an `AssertionError`.
* **function**: A function of the form `(actual, expected) => string`. It is
  called only when the assertion fails and should return a string to be used as
  the error message. Non-string return values are ignored and the default
  message is used instead.

If additional arguments are passed along with an `Error` or a function as
`message`, the call is rejected with `ERR_AMBIGUOUS_ARGUMENT`.

If the first item is neither a string, `Error`, nor function, `ERR_INVALID_ARG_TYPE`
is thrown.

## Step 1 — Output

According to the provided context, the `assert` statement in programming is used to verify invariants by checking that certain conditions hold true during execution. Specifically, the `node:assert` module in Node.js provides a set of assertion functions to perform these checks.

The purpose of an assert statement is to ensure that values or expressions meet expected conditions. If the condition being asserted is false (i.e., the values are not equal or the expression evaluates to a falsy value), an `AssertionError` is thrown. This helps catch bugs and incorrect assumptions early in the development process by signaling when something unexpected occurs.

For example, using `assert.equal(actual, expected)` checks if `actual == expected` (using loose equality). If they are not equal, an `AssertionError` is thrown with a message describing the failure.

In summary:

- **Definition:** An assert statement is a check that verifies if a condition or equality holds true.
- **Purpose:** To catch errors by throwing an exception when the asserted condition fails, helping developers identify and fix issues early.

**What is an assert?**  
An assert (assertion) is a statement in programming that checks whether a specific condition is true at a particular point in the code. If the condition evaluates to false, the assert triggers an error (often called an `AssertionError`), which usually stops the program or signals that something unexpected has happened.

**Why do asserts exist?**  
Asserts exist to help developers catch bugs and incorrect assumptions early during development and testing. They serve as internal sanity checks that verify the program is working as intended. By explicitly stating assumptions and invariants in the code, asserts help:

- Detect logical errors and invalid states quickly.
- Make debugging easier by pinpointing where and why a failure occurs.
- Document assumptions clearly within the code.
- Prevent the program from continuing in an invalid or inconsistent state, which could cause more complex problems later.

In short, asserts are a tool to improve code reliability, correctness, and maintainability by ensuring that certain conditions hold true during execution.
